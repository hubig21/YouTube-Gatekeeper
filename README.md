## 💡 為什麼需要 YTcF？

YouTube 演算法經常推送不合適、低品質或重複的影片。YTcF 讓你重獲演算法的主導權，不僅支援傳統的頻道與關鍵字過濾，更提供精準的「多維度矩陣過濾」、「協作頻道自動拆解」與「強阻模式」，適用於個人高效學習、家庭兒童防護等多種情境。

## ✨ 核心功能亮點

- **🚫 頻道黑 / 白名單**：支援 UC ID、`@handle`、頻道名稱或 Regex 比對
- **🎬 單支影片黑名單**：用 Video ID 封鎖特定影片，不影響該頻道其他內容
- **🤝 協作影片智慧解析**：自動拆解跨頻道合作影片，可選擇只封鎖特定參與者
- **⭐ 白名單獨享模式**：一鍵切換為「只顯示信任頻道」的極簡/兒童友善模式
- **🔤 關鍵字群組 + Regex**：可分別設定比對標題/描述，支援進階正規表達式
- **⏱️ 多維度過濾**：時長、觀看數、上傳日期、語言（BCP-47）、直播/首播、會員專屬、募款活動
- **🎯 過濾範圍矩陣**（進階）：11 種規則 × 首頁/訂閱/搜尋/觀看頁/頻道頁等頁面類型，各自獨立開關
- **🛡️ 頁面直接訪問強阻**：直接用網址或外部連結進入已封鎖內容時，可強制暫停 + 覆蓋層阻擋
- **🖱️ 快捷操作**：懸停快捷列、原生 ⋮ 選單整合、全域懸浮按鈕
- **🔬 診斷系統**：卡片生命週期追蹤、Debug Log 環形陣列（最高 10,000 筆），問題回報有據可查
- **💾 完整備份/匯出/分享**：JSON 全量備份、CSV 匯出、一鍵分享連結

完整功能操作說明請見下方〈使用說明〉。

## 功能說明

### 🚫 隱藏名單

新增你不想看到的頻道，該頻道在首頁、訂閱頁、搜尋結果等列表頁的卡片將被自動隱藏。

**新增方式：**
- **手動輸入**：在面板表單填入頻道名稱（必填）及 `@handle`（選填）後按新增
- **快捷按鈕**：滑鼠懸停影片卡片時，底部滑出操作列，點擊 🚫 即可即時封鎖
- **三點選單**：若設定為「三點選單」模式，點擊影片卡片的 ⋮ 選單，選擇「YtFC 隱藏此頻道」

**標籤功能：** 每個頻道可設定標籤，方便分類管理（例如「廣告帳號」、「農場頻道」）。

---

### ⭐ 白名單

加入你信任或想保護的頻道。白名單頻道永遠不受任何過濾規則影響，不會被隱藏名單、關鍵字等規則誤殺。

**白名單獨享模式：** 在 ⚙️ 設定中開啟「只顯示白名單頻道」，此時除白名單內的頻道外，其他所有頻道均會被隱藏。適合家長管控或極簡模式。

---

### 🎬 影片黑名單

封鎖特定影片 ID，即使不封鎖該頻道也能擋掉單支影片。常見用途：遮蔽特定爭議影片、屏蔽不感興趣的單集。

- 支援輸入影片 ID（11 字元）或完整 YouTube URL
- 加入後**永遠強制阻擋**，不受過濾範圍矩陣控制
- 直接透過影片 URL 進入時，也會顯示阻擋畫面（需在設定中啟用「強制阻擋」）

---

### 🔤 關鍵字過濾

依影片標題或描述中的關鍵字過濾。關鍵字以**群組**為單位管理，每個群組可個別啟用／停用。

**建立群組步驟：**
1. 點擊「＋ 新增群組」輸入群組名稱
2. 選擇套用範圍：標題、描述，或兩者皆套用
3. 在群組內新增關鍵字
4. 確認群組右側開關為「啟用」狀態

**群組優先順序：** 可拖動調整群組順序，上方群組優先判斷。

## 進階功能詳解

### 啟用過濾範圍（高級）

「過濾範圍」讓你針對每種過濾規則，指定在哪些 YouTube 頁面類型生效。適合需要精細控制的進階使用者。

#### 啟用步驟

1. 進入 ⚙️ **設定** 頁籤
2. 滾動至最底部，勾選「**啟用過濾範圍 (高級)**」
3. 點擊「💾 儲存設定」
4. 頁籤列出現「🎯 **過濾範圍**」，點擊進入

#### 矩陣介面說明

介面呈現 **11 種規則 × 7 種頁面** 的矩陣：

**頁面類型：**

| 代碼 | 說明 |
|------|------|
| 🏠 首頁 | youtube.com 首頁 |
| 📨 訂閱 | 訂閱頁面 |
| 🔍 搜尋 | 搜尋結果頁 |
| 🎬 影片頁 | 觀看影片時的側邊推薦 |
| 📺 頻道頁 | 進入特定頻道時 |
| 🔥 熱門 | 熱門影片頁面 |
| 📄 其他 | 其他頁面 |

**規則類型：**
頻道隱藏名單、影片黑名單、關鍵字、會員影片、直播／首播、募款活動、上傳日期、觀看數、語言、影片時長、頻道公告。

#### 操作方式

- **點擊格子**：切換該規則在該頁面的啟用狀態（綠色 = 啟用、灰色 = 停用）
- **行末「✓ 全部啟用」**：該規則在所有頁面全開
- **行末「✕ 全部關閉」**：該規則在所有頁面全關
- **底部「全部重設為啟用」**：恢復預設（所有規則在所有頁面生效）
- **當前頁面**：以特殊樣式標示，方便即時對照

#### 應用範例

**範例 1｜允許在頻道頁看到隱藏名單頻道的影片**
> 取消勾選「頻道隱藏名單」× 「頻道頁」
> → 瀏覽封鎖頻道的頻道頁時，仍可正常看到影片；但在首頁等列表頁仍會被隱藏

**範例 2｜只在首頁過濾關鍵字**
> 對「關鍵字」規則，只保留「首頁」勾選，其餘頁面取消
> → 搜尋特定標題時不受關鍵字過濾影響

**範例 3｜訂閱頁不過濾直播**
> 取消勾選「直播 / 首播」× 「訂閱」
> → 訂閱的頻道直播仍會出現在訂閱頁，但首頁不顯示

### Regex 模式

關鍵字群組支援 JavaScript 正規表示式（Regular Expression），讓你以更彈性的方式比對影片標題或描述。

#### 啟用方式

在關鍵字群組內新增關鍵字時，勾選「**Regex**」欄位即可為該關鍵字啟用正規表示式模式。

#### 使用規則

- **不需要**加 `/` 斜線或 `/i` 旗標，直接輸入 pattern
- 預設為**不區分大小寫**比對
- 反斜線（`\`）在介面中直接輸入即可，不需要額外跳脫

#### 常用範例

| Pattern | 說明 |
|---------|------|
| `(廣告\|業配\|贊助)` | 標題含「廣告」、「業配」或「贊助」任一 |
| `(股票\|投資\|理財)` | 標題提到任一財經相關詞彙 |
| `EP\.?\d+` | 集數格式：EP1、EP.1、EP 1 等 |
| `^(?!.*官方).*$` | 標題**不含**「官方」的影片（負向先行斷言） |
| `\d{4}年` | 標題含四位數字年份（如「2024年」） |
| `(LIVE\|直播\|STREAM)` | 各種直播標示 |

#### 注意事項

- Regex 只在**該關鍵字**啟用，同一群組內其他關鍵字可繼續使用純文字
- 若 pattern 格式錯誤（如括號不匹配），該關鍵字將自動退回純文字模式
- 過於複雜的 pattern 可能影響效能，建議優先使用 `(a|b|c)` 形式而非 lookahead

### 兒童模式設定技巧

透過組合現有功能，可以建立一個「白名單專享 + 危險內容自動過濾」的兒童友善瀏覽環境。

> ⚠️ **重要警語：** 本腳本僅過濾首頁、搜尋、推薦等列表頁，無法阻止直接輸入影片 URL，也無法偵測影片的實際內容。**強烈建議搭配 YouTube Kids、家長監護軟體（Google Family Link 等）或路由器層級的 DNS 過濾同時使用。**

#### 完整設定步驟

**第 1 步｜建立白名單**
進入 ⭐ **白名單** 頁籤，將孩子可以觀看的頻道逐一加入。
例如：@PBSKids、@SesameStreet、@CocomelonOfficial

**第 2 步｜啟用白名單獨享模式**
進入 ⚙️ **設定**，開啟頂部的「⭐ 只顯示白名單頻道」。
啟用後，除白名單內的頻道外，所有其他頻道均會被隱藏。

**第 3 步｜封鎖直播**
在設定中開啟「📡 直播 / 首播」區塊，同時勾選：
- 隱藏直播中
- 隱藏即將首播 / 即將直播（等候中）

直播聊天室是常見的風險來源，建議全數封鎖。

**第 4 步｜建立危險內容關鍵字群組**
進入 🔤 **關鍵字** 頁籤，建立名為「危險內容」的群組，套用範圍選擇「標題」：

加入以下關鍵字（可依需求調整）：
```
暴力、血腥、恐怖、成人、賭博、槍、毒品
```

若要更有效率，可開啟 Regex 模式，輸入：
```
(暴力|血腥|恐怖|成人|賭博|18禁|限制級)
```

**第 5 步（建議）｜限制影片日期**
在設定中開啟「📅 上傳日期」，設定「隱藏 30 天前上傳的影片」。
避免演算法推送過時的爭議性內容。

**第 6 步（建議）｜語言過濾**
在設定中開啟「🌐 語言過濾」，選擇「僅顯示指定語言」，只勾選孩子的母語。
可有效過濾大量未知語言的內容。

**第 7 步（建議）｜搭配密碼鎖定**
在設定中設定「密碼鎖定」，避免孩子自行修改過濾設定。

#### 搭配過濾範圍的進階設定

啟用「過濾範圍（高級）」後，可進一步細化兒童模式：

- **首頁、訂閱、搜尋**：所有規則全開
- **影片頁側邊欄**：開啟所有規則，避免側邊推薦出現不當內容
- **頻道頁**：可放鬆「頻道隱藏名單」規則，讓家長進入特定頻道做確認

## 快捷操作

| 操作 | 說明 |
|------|------|
| 左鍵點擊頂部 🔍 | 開啟管理面板 |
| 右鍵點擊頂部 🔍 | 切換過濾器開啟 / 暫停 |

**兩種快捷操作模式（在設定中切換）：**
- **快捷按鈕**：懸停影片時，底部滑出「🚫 隱藏此頻道」「⭐ 加入白名單」「🎬 隱藏此影片」三個按鈕
- **三點選單**：上述三個選項融入 YouTube 原生 ⋮ 選單，視覺更一致

## 密碼鎖定

在 ⚙️ 設定的「密碼鎖定」區塊中啟用：

- 設定後，每次開啟管理面板都需輸入密碼
- 未解鎖時，所有頁籤和全域開關均無法操作
- 關閉面板後自動重新鎖定
- 「Blocker 阻擋畫面」上的移除按鈕也受密碼保護（獨立驗證，不繼承面板解鎖狀態）

---

## 問題回報與診斷

若遇到畫面閃爍、過濾失效或卡片延遲問題：

1. 開啟管理面板，切換至「使用說明」或點選 Tampermonkey 選單中的「🔬 啟用診斷模式」
2. 點擊「🪲 開始記錄問題」並重現你遇到的異常現象
3. 點擊「⏹️ 停止並匯出記錄」下載診斷日誌（`ytcf-diag-xxx.log`）
4. 前往 [GitHub Issues](https://github.com/hubig21/YouTube-Gatekeeper/issues) 提交回報並附上日誌檔案

## 注意事項

- 腳本僅過濾**列表頁卡片**，無法過濾影片播放頁的實際內容
- Shorts 不在過濾範圍內，建議搭配專用的 Shorts 過濾腳本
- YouTube 頻道頁不含 UC ID 時，比對主要依賴 `@handle` 和頻道名稱
- 若封鎖頻道的卡片仍出現，可嘗試重新整理頁面或在管理面板按「儲存設定」
- 設定儲存於瀏覽器 localStorage，清除瀏覽器資料前請先匯出備份
